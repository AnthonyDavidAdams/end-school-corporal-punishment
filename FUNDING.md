# Funding

Money donated to this project is spent on, in this order:

1. Agent compute for the task queue in `tasks/README.md` (district scans, claim verification, bill watching).
2. Public records fees for district discipline records.
3. Printing and travel for testimony at school board meetings and legislative hearings.

Spending is logged in this file by month once the first dollar arrives.

Sponsor through GitHub Sponsors on this repository. If you would rather give compute than money, see `CONTRIBUTING.md`.
