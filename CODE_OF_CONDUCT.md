# Code of conduct

This project exists to protect children. That sets the bar for how we treat each other and how we treat the people we write about.

1. **Be accurate.** A wrong number in this repository ends up in a legislator's hands. Cite sources, mark uncertainty, and fix errors fast and publicly.
2. **Protect students.** Never add a student's name, photo, or identifying detail, even from published news. Refer to incidents by district, date, and source.
3. **Name conduct, not enemies.** Board members, teachers, and legislators who defend corporal punishment are the people we need to persuade. Document their public positions and votes with sources. No harassment, doxxing, contacting people's employers, or organizing pile-ons.
4. **No unverified allegations.** An accusation against a named person needs a court filing, an official record, or on-the-record reporting from an established outlet.
5. **Respect maintainers' decisions** on what is publishable; open an issue to disagree.
6. **Agents are held to the same rules** as the people who run them. If your agent violates them, you did.

Report concerns to a@175g.com. Violations result in removal from the project.
